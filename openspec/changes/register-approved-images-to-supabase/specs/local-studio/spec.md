## ADDED Requirements

### Requirement: STU-005 승인 전송과 로컬 거래의 일관성

스튜디오와 승인 CLI MUST 같은 이미지 등록 모듈을 사용한다. 스튜디오는 선택한 한 항목만, CLI는 승인 결과의 해당 종류만 처리한다. 전송 후 현재 파일 revision을 다시 대조해 외부 변경은 보존하고 오래된 반영은 거부한다. 등록 상태·공개 매니페스트·재료 소스 해시는 같은 복구 가능한 거래에 포함한다. 전송 실패는 원격 응답/키를 노출하지 않는 오류로 알리고 사용자가 설정·연결을 보완해 재시도할 수 있게 한다.

#### Scenario: 전송 중 외부 변경

- **WHEN** 업로드를 기다리는 동안 본문·이미지·매핑·공개 등록 기록이 외부에서 바뀐다
- **THEN** 최종 반영은 409로 거부하고 외부 수정과 로컬 초안을 유지한다.

#### Scenario: 중단된 등록 복구

- **WHEN** 로컬 등록 거래가 일부 파일 반영 후 중단된다
- **THEN** 기존 복구 절차로 등록 상태·공개 매니페스트·재료 소스 해시를 이전 바이트로 함께 복구하고 외부 수정은 덮어쓰지 않는다.
