# 최종 승인 이미지 Supabase 등록

## Why

이미지의 기존 이관은 완료됐지만 수집 스킬의 최종 등록과 스튜디오 승인·CLI는 로컬 상태만 변경했다. 새 승인 이미지가 실제 Storage와 공개 빌드에 함께 포함되도록 연결한다.

## What Changes

- 기존 승인 평가기를 임시 sparse staging에서 실행하고 동일 이미지 등록 모듈로 원본·파생 전송/다운로드 해시·익명 공개 읽기를 검증한다.
- 스튜디오의 한 항목 승인과 CLI `--write`를 같은 거래 경로로 연결한다. 전송 실패에는 등록하지 않고 동시 변경은 409로 보존한다.
- 기존 이관 evidence를 유지하며 새 공개 등록 매니페스트를 별도 기록해 빌드에서 병합한다. 신규 재료 소스 해시도 같은 거래에서 갱신한다.
- 수집·정규화·이미지 스킬과 로컬 실행·재시도 문서를 갱신한다. 새 JPEG는 로컬 보존/Git 제외, 공개 등록 기록은 Git 포함한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `content-review`: CON-007 추가. CON-001~003의 현재 승인·재료 선행 검증을 유지하고 CON-004~006의 기존 이관 기준 커밋 검증은 그대로 둔다. 신규 등록은 검수 결과를 승인 근거로 사용한다.
- `local-studio`: STU-005 추가, STU-001·STU-002의 revision/복구 계약을 업로드 대기와 공개 등록 파일에도 적용한다.
- `web-platform`: WEB-003의 공개 원본 없는 빌드에 신규 등록 기록을 합친다. 기존 자산 검증·배포 경계를 유지한다.
