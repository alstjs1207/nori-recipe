# 스튜디오 신규 놀이 사용 가이드

## Why

신규 놀이 수집·검수·승인·서비스 반영 절차를 스튜디오 안에서 바로 확인하려는 사용자 요청이다. 한 번만 수행하는 키 설정은 사용 가이드에서 제외한다.

## What Changes

- 공유 사이드바에 사용 가이드를 추가하고 `/guide` 읽기 전용 페이지를 제공한다.
- 수집 요청 → 검수 화면 → 새 재료 검수 → 놀이 승인/이미지 업로드 → Preview/운영 반영의 다섯 단계를 안내한다.
- 수정 요청·이미지 준비·업로드 실패·외부 변경 시 재개 방법과 메뉴 바로가기를 제공한다. 모바일에서도 기존 스튜디오 레이아웃을 사용한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `local-studio`: STU-006 사용 가이드. STU-001의 허용 경로·읽기 전용 계약을 유지한다.
- `content-review`: CON-003·CON-007의 사용자 승인·재료 선행 검수·Supabase 검증·로컬 등록/공개 배포 경계를 안내에 반영하며 실제 상태를 바꾸지 않는다.

## Impact

기존 원본 `/Users/msyu/study/play-recipe`의 preview 작업 폴더에서 작업한다. 이전 Supabase 파이프라인 미커밋 변경을 보존한다. 가이드는 키 설정을 노출하지 않고 조회로 수집·승인·이미지 업로드·배포를 수행하지 않는다. 정적 file:// 검수에 작동하지 않는 서버 링크를 추가하지 않는다. GOV-001~003의 명세·소스 분류·검증을 갱신한다. 커밋·푸시·운영 배포는 요청 범위에 없다.
