# Design

## Context

토스 전용 요약 헤더는 공통 WebShell의 분기이고 AI 안내 문단은 네이티브 연결을 담당하는 TossPlatform에 있다. 기존 웹의 헤더와 기기 저장 계약을 유지해야 한다.

## Goals / Non-Goals

상단에서 요청한 세 요소와 그 요소만을 위한 공간을 제거한다. 네이티브 내비게이션 테마·SafeArea 보정·데이터·추천은 변경하지 않는다.

## Decisions

- 토스에서는 공통 요약 header를 렌더링하지 않는다. CSS로 감추는 대신 DOM에서 제외해 공간과 보조기술 탐색 대상도 제거한다.
- TossPlatform의 연결·오류·사용자 전환 처리는 유지하고 안내 문단만 제거한다. 이미지의 AI 라벨과 설정의 설명은 기존 경로로 제공한다.
- 월령은 PageFooter의 내 설정과 기존 온보딩에서 계속 설정한다. 다른 위치에 대체 상단 버튼을 추가하지 않는다.

## Risks / Trade-offs

상단 설정 단축 버튼은 사라진다. 기존 내 설정 진입과 월령 저장 화면을 검증해 설정 기능의 접근성을 보존한다. 일반 웹은 대상 분기를 확인하고 기존 프로필 버튼을 유지한다.
