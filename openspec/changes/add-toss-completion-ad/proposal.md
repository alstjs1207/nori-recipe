# Proposal

## Why

사용자가 토스 미니앱에서 오늘 추천 놀이 3개 완료 후 광고를 요청했다. 공식 가이드는 완료 후 흐름 전환에 전면형 광고를 권장하며 개발에는 테스트 ID와 콘솔 QR를 요구한다.

## What Changes

- TOSS-001의 광고 없음 제한을 사용자 요청으로 변경하고 TOSS-007의 완료 광고를 추가한다.
- TOSS-005 개인정보 고지와 TOSS-006 빌드 보고서·테스트/운영 환경을 갱신한다.
- REC-004의 기존 고정 추천·완료 이력·축하 화면을 유지한다. 일일 초기화나 새 세트 자동 생성은 추가하지 않는다.
- LOG-001, LOC-001/002, PRI-001/002/003/004, WEB-001/002/003과 TOSS-002/003/004의 저장·분석·공유 정책을 유지한다. 광고로 데이터 저장이 실패하거나 뒤로가기를 막지 않는다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `toss-miniapp`: 추천 3개 완료 전면형 광고와 테스트·운영 모드 분리.

## Impact

원본 `/Users/msyu/study/play-recipe` preview에서 작업하며 별도 작업 폴더를 만들지 않는다. 공식 SDK 3.10.0을 유지한다. SDK에는 광고 그룹 ID만 전달하고 완료 기록은 메모리에서 로컬 비교한다. 추가 저장 키·웹 분석·DB 마이그레이션은 없다. 콘솔 광고 그룹 ID와 실제 토스앱 QR 검증은 외부 준비사항이다.
