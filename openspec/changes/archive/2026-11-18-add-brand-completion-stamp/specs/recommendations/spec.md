## MODIFIED Requirements

### Requirement: REC-004 홈 추천 고정과 완료 표현

홈 SHALL 재료 기준 3개를 목표로 추천을 고정 보관하고 같은 문맥에서는 일반 순위 변경만으로 바꾸지 않는다. 완료 상태와 모두 완료 메시지·축하 효과를 표시한다. 웹/토스에서는 상단 큰 카드와 나머지 추천 카드를 공통 제목·완료 개수 아래 연속 배치하며 상황별 탐색은 추천 세트 뒤에 표시한다. 완료한 추천은 흐린 그림과 꽃 로고·`참 잘했어요`·`놀이 완료`가 들어간 원형 이미지 도장으로 구분하되 다시 열 수 있다. 월령·재료·제외 재료·준비 확인 및 콘텐츠 적격성이 달라지면 현재 조건으로 복구한다. 현재 키에는 놀이 개수도 포함된다. 고정 UI 전체와 완료 후 다음 세트 시점은 GAP-001·GAP-002 검증 대상이다.

#### Scenario: 같은 문맥

- **WHEN** 점수만 달라지고 기존 항목은 적격이다
- **THEN** 저장된 추천 ID를 유지한다.

#### Scenario: 재료 편집

- **WHEN** 오늘 재료를 변경한다
- **THEN** 기존 세트와 보호자 확인을 폐기한다.

#### Scenario: 삭제·부적격

- **WHEN** 저장된 놀이가 없어지거나 적격성을 잃는다
- **THEN** 현재 후보로 세트를 보충한다.

#### Scenario: 웹 추천 세트와 완료 카드

- **WHEN** 웹 홈에서 추천 중 일부를 완료한다
- **THEN** 같은 추천 ID를 유지하며 완료 개수와 해당 카드의 도장을 표시하고 상황별 탐색을 추천 사이에 끼우지 않는다.
