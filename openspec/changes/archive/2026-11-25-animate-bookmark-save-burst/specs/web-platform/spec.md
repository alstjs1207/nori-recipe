## ADDED Requirements

### Requirement: WEB-007 북마크 저장 모션

웹/PWA/토스의 공통 저장 버튼 SHALL 기존 북마크 아이콘·보라색·44px 원형 버튼과 놀이별 저장/저장 취소 접근성 이름을 유지한다. 사용자 클릭 뒤 실제 saved 상태가 바뀔 때만 Like burst의 아이콘520/13·채움300/26 unit mass 스프링을 프레임당4회·최대1/30초로 적분한다. 저장 성공에는8개 점이550ms 동안 반경10px에서32/38px로 퍼지며 축소·소멸하고 취소에는 작은 딥과 채움 해제만 표시한다. 기존 로컬 저장·실패 안내·분석 동의 정책을 유지하며 숫자 카운터·자동 반복은 추가하지 않는다.

#### Scenario: 저장과 취소

- **WHEN** 홈·탐색·상세·저장 목록에서 북마크를 눌러 실제 저장 상태가 바뀐다
- **THEN** 저장에는 북마크 팝·보라색 채움·점 확산을 표시하고 취소에는 작은 딥과 채움 해제를 표시한다. 점은 카드의 둥근 모서리 밖에서도 잘리지 않고 링크 이동·버튼 크기·기존 모서리를 유지한다.

#### Scenario: 초기 조회와 실패

- **WHEN** 저장 목록을 처음 불러오거나 저장에 실패해 saved 상태가 유지된다
- **THEN** 축하 모션을 재생하지 않으며 실제 저장 상태와 기존 실패 안내를 유지한다.

#### Scenario: 모션 축소와 정리

- **WHEN** 모션 축소 설정이 켜지거나 문서가 숨겨지거나 버튼이 unmount된다
- **THEN** 모션 축소·문서 숨김에는 점을 지우고 최종 저장 상태를 즉시 표시하며 안정·unmount에서는 프레임을 멈추고 구독을 해제한다. 키보드 Enter/Space로도 기존 저장을 실행할 수 있다.
