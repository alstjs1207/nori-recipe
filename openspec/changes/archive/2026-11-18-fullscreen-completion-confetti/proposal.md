# Proposal

## Why

추천3개를 모두 완료하면 폭죽이 `오늘의 놀이를 모두 완료했어요` 배너 내부에만 나타난다는 사용자 보고를 확인했다. 배너 내부의 absolute 배치·overflow:hidden과160px 이동 거리 때문에 화면 전체의 축하로 보이지 않는다.

## What Changes

- REC-004: 웹/PWA/토스 공통 홈의 축하 효과를 document.body의 고정 포털로 옮겨 현재 화면 전체에 표시한다. 배너·스크롤·탭 장면의 clipping에 제한되지 않는다.
- 약3.3초 후 제거하고 홈을 벗어나면 즉시 정리한다. 포인터·키보드 조작과 스크린리더 안내를 방해하지 않으며 동작 줄이기 설정에서는 배너만 표시한다.
- REC-001/002/003/004/005, WEB-002/005/006, LOG-001/002/003, LOC-001/002, PRI-001/002/003/004, TOSS-001/002/003/007의 추천·완료 기록·광고·진입/스크롤·미저장 초안·메뉴·로컬 저장·분석 정책을 유지한다. 네이티브 화면의 기존 배너는 유지한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `recommendations`: 홈 추천 전체 완료의 화면 전체 축하 효과.

## Impact

원본 `/Users/msyu/study/play-recipe` preview에서 기존 미커밋 변경을 보존한다. 기존 React DOM 포털과 CSS로 구현하고 React19.1에 맞는 @types/react-dom 개발 타입만 추가한다. 새 런타임 패키지·이미지·저장·작업용 폴더는 없다. 원본4327 서버에 로컬 빌드를 반영하며 테스트 기록은 별도4330 origin에서 작성한다. 커밋·푸시·배포는 포함하지 않는다.
