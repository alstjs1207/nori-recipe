# Proposal

## Why

사용자가 홈 안내를 앱에 어울리는 스타일로 바꾸는 제안(일반 재료는 정보 아이콘과 보조 문장, 보호자 도움은 작은 카드)을 선택했으며 주변 글씨보다 작게 요청했다. 기존14px 라벤더 배경·왼쪽 세로선이 두 안내에 동일하게 쓰여 인용구처럼 보였다.

## What Changes

- REC-002: 일반 재료 안내를 정보 아이콘과12px 회보라색 문장으로 표시하고 배경·세로선을 제거한다. 추가 준비물의 중복 도입 문장은 줄인다.
- REC-003: 상위 월령 안내를 ‘함께 도와주세요’ 제목·보호자 아이콘·둥근 연한 라벤더 카드로 표시하며 제목·본문 모두12px로 맞춘다. 놀이명·기본 월령·보호자 도움 조건은 보존한다.
- REC-001/004/005, WEB-002/005/006, LOG-001/002/003, LOC-001/002의 추천 안전·고정·완료/폭죽·탐색·기록·저장 정책은 유지한다. 공통 웹/PWA/토스 홈 스타일 변경이며 기존 네이티브 레이아웃은 범위 밖이다.

없음.

### Modified Capabilities

- `recommendations`: 재료 안내와 상위 월령 보호자 안내의 시각적 위계.
