## MODIFIED Requirements

### Requirement: TOSS-007 추천 세트 완료 전면형 광고

토스 대상 SHALL 현재 추천 3개 중 마지막 미완료 놀이의 새 기록 저장이 성공한 뒤 홈으로 돌아오는 시점에 공식 `loadFullScreenAd`·`showFullScreenAd`로 전면형 광고를 최대 한 번 표시한다. 기록은 광고와 무관하게 먼저 저장하고 기존 완료 메시지·축하 효과·새 추천 기능을 유지한다. 기록 저장 화면에서 완료 후 광고가 표시될 수 있음을 안내한다. 일반 웹·네이티브에는 광고 SDK를 추가하지 않는다.

#### Scenario: 세 번째 놀이 저장 후 홈 복귀
- **WHEN** 현재 추천은 중복 없는 3개이고 새 저장 기록을 제외하면 미완료였던 세트가 모두 완료되며 미리 로드한 광고가 준비돼 있다
- **THEN** 같은 광고 그룹 ID로 광고를 한 번 표시하고 닫힘 뒤 다음 광고를 순차 로드한다. 놀이·기록·프로필 식별자는 광고 SDK에 전달하지 않는다.

#### Scenario: 반복 진입과 과거 기록
- **WHEN** 일반 홈 재진입·재실행·이미 완료된 놀이의 재기록·추천 외 놀이 완료·3개 미만 세트 완료가 발생한다
- **THEN** 광고를 표시하지 않는다. 노출 판단은 현재 추천 회차의 완료 기록을 기준으로 하며 날짜가 바뀌었다는 이유로 기록이나 세트를 초기화하지 않는다. 명시적 새 추천은 같은 놀이여도 새 회차이며 그 회차의 세 번째 완료는 새 노출 기회가 된다.

#### Scenario: 광고 미지원과 실패
- **WHEN** 광고가 미지원·로드 중·오류·노출 실패이거나 홈을 떠났거나 기기가 숨김 상태다
- **THEN** 해당 완료 기회의 광고를 건너뛰고 늦게 표시하거나 자동 재시도하지 않는다. 저장·축하·탐색·뒤로가기를 광고 때문에 막지 않으며 콜백 구독을 해제한다.

#### Scenario: 테스트와 운영 빌드
- **WHEN** 개발 실행이나 기본 토스 번들을 만든다
- **THEN** 공식 전면형 테스트 ID를 사용한다. 운영 모드는 별도 지정과 콘솔 광고 그룹 ID를 요구하며 보고서에 모드·그룹·위치를 남긴다. 실제 테스트 광고는 콘솔 QR의 토스앱에서 확인하고 모의 SDK 결과와 구분한다.
