## ADDED Requirements

### Requirement: WEB-006 상단 월령 버튼

일반 웹/PWA의 상단 월령 버튼 SHALL 아이콘·이름 첫 글자·흰색 아바타 없이 월령 또는 월령 설정 문구와 화살표만 표시한다. 기존 배경·문구별 버튼 너비·41px 높이·접근성 이름·키보드와 클릭에 의한 프로필 설정 이동을 유지한다. 아이 이름·월령 등 저장된 데이터와 토스의 별도 헤더는 변경하지 않는다.

#### Scenario: 상단 월령 버튼

- **WHEN** 아이 이름 설정 여부와 관계없이 일반 웹/PWA 상단 월령 버튼을 본다
- **THEN** 월령 문구와 화살표만 표시하고 기존 버튼 영역과 프로필 설정 이동을 유지한다.
