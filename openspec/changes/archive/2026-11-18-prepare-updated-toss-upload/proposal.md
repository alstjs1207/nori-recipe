# Proposal

## Why

사용자가 preview에 반영한 홈·완료·스크롤·미저장 기록·마이 메뉴 개선을 토스 인앱에도 반영해 파일 생성과 콘솔 업로드까지 요청했다. 공통 화면은 포함되지만 토스 전용 CSS에4개 메뉴 시절의44px 높이가 남아 있어5개 메뉴의 터치 영역을 맞춘다.

## What Changes

- TOSS-003: 플로팅 메뉴를5등분 grid와56px 최소 터치 높이로 맞춘다. 기존 브랜드 크기·안전 영역·상세/피드백 메뉴 숨김을 유지한다.
- WEB-005/REC-004: 토스 통합 검증에서 홈 대표 그림이 늦게 로드되며 복구 위치가533px→886px로 밀리는 결함을 재현했다. 대표 그림의1:1 공간을 미리 확보하고 비활성 화면의 스크롤 저장을 차단한다. 로딩 뒤에도 목록 복귀 위치를 유지한다.
- TOSS-006/007: 공식 SDK3.10.0에서 최신 코드를 QR용 테스트 광고 ID로 패키징하고 해시·크기·모드와 콘솔 버전/서버 빌드 상태를 기록한다.
- REC-004, WEB-005/006, LOG-001/002/003, TOSS-001/002/004/005/007의 추천·로고 도장·전체 화면 폭죽·새 진입 상단/뒤로 목록 복귀·미저장 세션 초안·사용자별 기기 저장·공유·고지·광고 조건을 유지한다. 실제 광고 노출·심사·정식 출시는 별도다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `toss-miniapp`:5칸 플로팅 메뉴의 터치 영역과 최신 번들 인계.
- `web-platform`: 비활성 화면 스크롤 저장 차단과 이미지 로딩 후 복원 유지.
- `recommendations`: 홈 대표 그림의 로딩 전 공간 확보.

## Impact

원본 `/Users/msyu/study/play-recipe` preview를 재사용한다. 웹 dist/기존 정상 토스 산출물·사용자 기록을 보존한다. 관리 토큰/새 업로드 CLI 없이 로그인된 노리공방의 노리 레시피 콘솔에서 새 버전을 등록한다. 새 worktree/clone은 만들지 않는다.
