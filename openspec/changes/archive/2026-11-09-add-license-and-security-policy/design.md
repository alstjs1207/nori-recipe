# 라이선스와 보안 정책 적용

## Context

프로젝트에는 ASSET-LICENSE.md가 있고 이미지의 외부 사용 권리를 제한한다. 코드 라이선스 추가를 이미지·수집 원문·의존성 전체의 재허가로 확대하지 않는다.

## Goals / Non-Goals

목표는 자체 코드의 Apache 2.0 적용과 취약점 제보 경로 제공이다. 원격 보안 기능 활성화나 서비스 보안 진단은 포함하지 않는다.

## Decisions

- LICENSE는 Apache 공식 원문을 그대로 사용한다. 범위와 저작권은 NOTICE/README에 분리해 원문을 변형하지 않는다.
- 시각 에셋은 기존 별도 라이선스, 수집 콘텐츠·데이터셋·제3자 자료는 이번 허가에서 제외한다.
- SECURITY의 비공개 연락처는 기존 공통 고지의 alstjs1207@naver.com을 사용한다. 고정 SLA·포상금을 새로 약속하지 않는다.
- GOV-004는 source-reviewed로 기록한다. 새 문서를 source-index와 정책 변경 검사 대상에 포함한다.

## Risks / Trade-offs

저장소의 소스 라이선스만 보고 이미지나 수집 원문까지 자유 이용할 수 있다고 오해할 수 있어 범위를 연결한다. 원격 GitHub 보안 기능이 활성화됐다는 주장은 하지 않는다.

## Migration Plan

서비스·데이터 이관은 없다. 문서·근거·분류를 확인하고 현재 명세/delta가 같음을 대조한 뒤 완료 change를 보관한다.

## Open Questions

없음. 원격 기능 설정이나 추가 보안 진단은 별도 요청 범위다.
