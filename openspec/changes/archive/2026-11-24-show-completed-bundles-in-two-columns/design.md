# 최근 완성 묶음 두 열

최근3묶음을 날짜별 그룹 안의 세로 목록 대신 묶음별 날짜를 포함하는 두 열 그리드로 렌더링한다. 날짜가 다른 묶음도 같은 행에 놓인다. 최신 순서와3개 제한은 유지하고 월별 전체 보기는 기존 날짜별 그룹과3열 상세 배열을 유지한다.

600px 이상은 각 셀의 기존 팬을 보여주며 ResizeObserver가 셀 폭에 맞춘다. 기존 호버·키보드 펼침과 스프링은 유지한다.

600px 미만은 두 셀 안에서 세 카드를 모두 축소하면 제목과 탭 영역이 작아지므로 이미지/순번/제목이 붙은 접힌 카드 표지 버튼을 보여준다. 선택한 한 묶음만 전체 행에 걸쳐 실제 팬과 상세 링크를 표시한다. 표지 버튼에 aria-controls/aria-expanded를 제공하고 열면 펼친 영역, 닫으면 원래 표지 버튼으로 포커스를 옮긴다. 펼친 영역에서 다음 Tab으로 첫 상세 링크에 도달한다. 열자마자 첫 카드를 자동 강조하지 않아 터치 대상이 움직이지 않도록 한다. 접힌 상세 영역은 display:none으로 탭 순서에서 제외한다. 넓은 화면에서는 표지와 접기 버튼을 숨긴다.

실제 완료 기록/회차/날짜/월별 조회를 수정하지 않고 표지만 실제 세 놀이 데이터에서 만든다. 별도 저장 상태나 라이브러리는 추가하지 않는다.
