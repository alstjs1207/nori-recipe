# Design

## 원본 확인

구현 전에 https://designbookmark.com/motion-src/bottom-bar/index.html, bar.css, bar.js 및 ../shared/tokens.css, base.css, motion.js를 읽고 브라우저에서 원본을 확인했다. 텍스트 너비 측정, width/opacity/padding 보간, 아이콘 x=.72/v=6 팝, 실제 링크 offset을 따라가는 강조 배경을 기존 React에 이식한다. 원본 문서의 전역 theme·autoplay·외부 스크립트는 가져오지 않는다.

## 선택과 레이아웃

AppLink와 usePathname을 그대로 사용한다. 경로가 바뀐 뒤 해당 메뉴에 모션을 적용하며 수정키·새 탭 클릭을 가로채지 않는다. /start, /history, /settings 별칭과 aria-current=page를 보존한다. 접힌 라벨은 시각 표현이며 각 링크의 접근성 이름은 항상 유지한다. 탭 역할 대신 실제 페이지 링크를 사용한다.

일반 웹은 기존 800px 이하에서 하단, 그보다 큰 화면에서는 기존 헤더를 표시한다. 토스는 공통 하단 바를 표시한다. 320px 화면에서도 모든 링크의 최소 터치 영역 44×56px를 지키고 선택 메뉴에만 텍스트 공간을 더한다. 바는 최대420px·32px radius, 강조 배경은 라벤더·25px radius, 기존 폰트·보라색을 쓴다. 좌우 안전 여백으로 공간이 좁아지면 바의 바깥 여백을 줄여 최대296px의 최소 너비를 확보하되 shell 너비를 넘지 않는다. 본문 밖 shell의 직접 자식으로 유지해 콘텐츠를 덮지 않으며 하단·좌우 안전 여백을 보존한다.

## 모션 수명

순수 스프링 엔진은 unit mass semi-implicit Euler로 프레임당 4회 적분하며 긴 프레임을 1/30초로 제한한다. 라벨300/26, 아이콘520/14, 강조 배경340/28을 사용한다. 경로 변경·현재 메뉴 재선택에만 rAF를 시작하고 안정 시 정지한다. 크기·폰트·표시 상태 변화에서는 실제 링크를 다시 측정하며 unmount/숨김에서 프레임과 구독을 정리한다. reduced-motion에서는 바로 최종 상태를 표시한다.

## 검증 범위

엔진 수렴·팝·빠른 재선택·긴 프레임 제한·즉시 종료를 자동 검사한다. 브라우저에서는 좁은 화면, 실제 링크 이동, 뒤로/앞으로, 재선택, 상세 숨김, 데스크톱 헤더, reduced-motion과 안전 여백을 확인한다. 토스 호스트/실기기 확인과 로컬 CSS 시뮬레이션을 구분한다.
