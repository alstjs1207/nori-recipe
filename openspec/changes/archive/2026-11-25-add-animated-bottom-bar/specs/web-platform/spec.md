## MODIFIED Requirements

### Requirement: WEB-006 월령 안내와 마이 메뉴

웹/PWA/토스 공통 주 메뉴 SHALL 발견·탐색·저장·기록·마이의5개 메뉴를 표시하며 상단 월령 버튼은 제거한다. 모바일 하단의 오른쪽 마이와 데스크톱 주 메뉴의 마이는 기존 /mypage 설정 화면으로 이동한다. 마이의 접근성 이름은 마이페이지이며 /mypage·/settings를 선택 표시한다. 하단은 선택한 메뉴의 글자만 펼치며 라벤더 강조 배경이 실제 링크 위치·너비를 따라 이동하고 아이콘이 팝 모션을 표시한다. 모든 링크는 시각적 라벨의 접힘과 무관하게 접근성 이름을 유지하며 작은 화면에서도 최소44px 너비·56px 높이의 전체 영역을 누를 수 있고 글자·아이콘이 겹치지 않아야 한다. 월령은 홈 본문 설명에 실제 프로필 기준으로 표시하며 미설정 월령을 임의로 만들지 않는다. 상세/피드백의 모바일 하단 메뉴 숨김과 안전 여백·저장된 데이터·기존 새 진입/복귀 정책을 유지한다.

#### Scenario: 마이 메뉴 진입

- **WHEN** 모바일 오른쪽 하단 또는 데스크톱의 마이를 누른다
- **THEN** 기존 마이페이지를 상단에서 표시하고 /mypage·/settings에서 마이를 선택 표시한다.

#### Scenario: 작은 화면의5개 메뉴

- **WHEN** 320px 이상의 좁은 화면에서 주 메뉴를 본다
- **THEN** 선택 항목에 텍스트 공간을 더하면서5개 항목 모두 최소44px 폭과56px 높이로 표시되어 겹치거나 가로 넘침 없이 전체 칸을 누를 수 있다.

#### Scenario: 홈 월령 안내

- **WHEN** 월령이 설정된 홈을 연다
- **THEN** 상단 월령 버튼 대신 홈 제목 아래 실제 월령 안내를 표시한다. 첫 방문의 미설정 월령은 임의로 표시하지 않는다.

#### Scenario: 선택 메뉴 모션과 복귀

- **WHEN** 메뉴를 누르거나 브라우저 뒤로/앞으로 또는 직접 링크로 선택 경로가 바뀐다
- **THEN** 실제 경로에 맞춰 라벨300/26·아이콘520/14·강조 배경340/28의 unit mass 스프링을 프레임당4회·최대1/30초로 적분해 표시한다. 자동 메뉴 순환은 없고 기존 진입/복귀·별칭·키보드 링크 동작을 유지하며 안정 시 프레임을 멈춘다.

#### Scenario: 모션 축소와 화면 변경

- **WHEN** 모션 축소 설정 또는 화면 크기·폰트가 바뀌거나 하단 메뉴가 숨겨진다
- **THEN** 모션 축소에서는 즉시 최종 상태를 표시하고 크기·폰트 변경 후 실제 링크 위치를 다시 측정한다. 숨김·unmount에서 프레임과 구독을 정리하며 안전 여백·데스크톱 헤더는 유지한다.
