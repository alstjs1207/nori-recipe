## MODIFIED Requirements

### Requirement: TOSS-003 토스 내 탐색과 화면 영역

토스 대상 SHALL 발견·탐색·저장·기록·마이의 공통 플로팅 하단 바와 안전 영역을 적용하며 최소44×56px 터치 영역, WEB-006의 선택 라벨·강조 배경·아이콘 스프링과 모션 축소 정책을 유지한다. 뒤로가기는 대화상자·앱 내 이전 화면·최초 화면 종료 순으로 처리한다. 중복 뒤로가기·설치·PWA 업데이트·웹 분석 동의 유도는 표시하지 않는다. 브랜드 헤더는 기존 꽃 로고·노리레시피 크기를 유지하고 공통 가족 요약·월령 단축 버튼·소개 문단은 숨긴다. 월령은 기존 설정·온보딩에서 수정한다. 호스트 상단 영역을 중복 적용하지 않으며 브랜드 상하padding0·홈 링크44px·본문 상단8px와 하단·좌우 안전 여백을 유지한다.

#### Scenario: 직접 상세와 뒤로가기
- **WHEN** 놀이 상세로 직접 진입한 뒤 뒤로간다
- **THEN** 앱 홈으로 이동할 수 있으며 최초 화면에서는 종료하고 대화상자가 열려 있으면 먼저 닫는다.

#### Scenario: 화면 영역 변경
- **WHEN** 안전 영역이 바뀌거나 화면을 이동한다
- **THEN** 좁은 화면에서도 선택 라벨 공간과5개 메뉴의 최소44px 너비·56px 높이를 유지하며 조작부가 가려지지 않고 구독·호출이 중복 누적되지 않는다.

#### Scenario: 공통 상단 요약 제거와 설정 접근
- **WHEN** 토스 미니앱의 화면을 연다
- **THEN** 꽃 로고와 노리레시피가 기존 크기로 표시되고 가족 요약·월령 단축 버튼은 표시하지 않는다. SDK top inset이 바뀌어도 shell 상단padding은0이며 브랜드 홈 링크44px와 본문 상단8px를 유지한다. 기존 내 설정에서 월령을 수정할 수 있다. 일반 웹의 마이 메뉴·홈 월령 안내 정책도 유지한다.
