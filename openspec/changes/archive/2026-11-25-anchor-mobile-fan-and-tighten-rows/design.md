# 표지 위치를 기준으로 펼치기

600px 미만의 실제 팬 패널을 한 셀 너비에 고정한다. 카드 폭은 표지와 동일한 min(150px, 셀 폭-28px), 높이는 표지의 실제 높이를 사용한다. 사진/순번/제목의 패딩·폰트와 상단14px도 일치시켜 가운데 카드가 클릭 전후 동일한 사각형에 있도록 한다. 자동 scrollIntoView를 제거한다.

원래 질량과 스프링으로 펼침을 진행하며 가운데 카드는 x/y/회전0을 유지한다. 나머지 두 카드는 왼쪽 열에서 오른쪽, 오른쪽 열에서 왼쪽으로 펼친다. 실제 회전과 확대 후 네 꼭짓점의 수평 경계를 계산해 바깥 카드만 화면 안에 맞춘다. 먼저 펼치는 카드가 더 바깥 카드보다 앞에 있어 각 카드의 선택 영역을 남긴다. 터치에서는 포커스에 따른 띄움을 적용하지 않아 탭 대상이 움직이지 않게 한다.

넓은 화면은 기존 팬 식과 호버를 유지한다. 모바일 클릭의 expanded 상태만 효과에 연결해 스프링 진입을 재생하고 동작 줄이기는 같은 기준점에서 즉시 펼친다. 표지 공간은 유지하되340~430px 최소 행 높이를 없애고 아래20px 여유·행 간격16px로 줄인다. 접기 영역을 다음 날짜 전에 두고 열기/접기에도 두 열의 위치가 변하지 않도록 실제 검증한다.
