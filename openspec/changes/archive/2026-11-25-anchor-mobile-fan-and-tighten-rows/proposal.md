# 모바일 원래 자리에서 카드 펼침과 행 간격 축소

## Why

사용자가 두 장의 실제 화면을 첨부하며 작은 화면에서 클릭한 카드가 행 중앙으로 옮겨지지 않고 원래 자리에서 펼쳐지고, 큰 위아래 여백도 줄이기를 요청했다.

## What Changes

- LOG-004: 두 칸 너비의 중앙 정렬 패널을 해당 셀 너비로 바꾸고 표지 가운데 카드의 크기/위치를 유지한다. 나머지 두 카드만 이웃 열 방향으로 펼치며 바깥 카드의 회전 경계만 행 안에 맞춘다.
- LOG-004: 모바일 클릭은 원래 스프링으로 펼치고 자동 스크롤하지 않는다.340~430px 행 높이 예약을 제거하고 표지 높이·접기 여유20px·행 간격16px로 축소한다.
- LOG-001/003·LOC-001/002·REC-004·WEB-002·TOSS-003/006의 데이터/날짜/조회·질량과 스프링·넓은 화면 호버·모션 감소·월별 배열·eval 차단은 유지한다.

## Capabilities

### Modified Capabilities

- `play-records`: 모바일 펼침 기준점과 행 간격.

## Impact

원본 preview에서 기존 미커밋 변경을 보존한다. 팬 컴포넌트·기존 모션 helper/회귀·호출부/CSS와 현재 spec/활성 delta/정책 anchor를 갱신한다. 커밋·푸시·배포·토스 파일 재생성은 요청하지 않았다.
