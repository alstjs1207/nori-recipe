# Design

기존 완료 묶음 조회/날짜 그룹을 그대로 사용하고 최근 기본 보기에서만 CompletedPlayFan을 렌더링한다. 각 놀이의 사진과 고정 제목은 같은 기존 AppLink에 묶어 키보드 탭 지점과 상세 이동을 유지한다. 월별 전체 보기에는 기존 figure3열을 그대로 렌더링한다. 반응형 축소는 묶음 컨테이너 폭을 관찰해 적용하며 사진만 transform하고 제목/날짜·단계 높이는 고정한다.

단위 질량 스프링을 원본과 같은 식·4substep·최대1/30dt로 적분한다. useLayoutEffect의 로컬 ref가 DOM transform을 그리며 프레임마다 React 상태를 갱신하지 않는다. IntersectionObserver·문서 visibility로 보이는 동안만 실행하고 모든 스프링이 수렴하면 rAF를 멈춘다. ResizeObserver와 media query 이벤트를 해제한다. 모션 감소는 즉시 최종 정적 상태로 맞추고 다시 해제해도 진입 모션을 반복하지 않는다. 기록 화면의 Set은 같은 묶음을 탭/전체 보기로 전환할 때 진입 모션을 다시 시작하지 않게 하며 영구 저장하지 않는다.

신규 스프링·전체 회귀·데스크톱/320px/393px 터치·포커스·모션 감소·정착/뷰 밖 프레임 중지·월별 배열·상세 이동/복귀를 검증한다. 이전 토스 eval 수정은 보존하고 실제 토스 빌드에서 다시 검사한다. 실제 토스앱 QR/광고 동작은 브라우저 모의 결과로 완료 처리하지 않는다.
