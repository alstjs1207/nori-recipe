## MODIFIED Requirements

### Requirement: WEB-004 정적 서비스 소개 페이지

웹 빌드 SHALL 앱과 분리된 웹 소개 `/intro`와 토스 홍보 `/toss-intro`를 생성한다. 놀이·재료·월령·발달영역 수치는 live 놀이와 검수 대기 제외 재료에서 계산한다. 화면 이미지는 실제 웹 캡처의 내용 해시 WebP를 쓰고 브랜드명은 ‘노리 레시피’로 표기한다. 동작 효과는 동작 줄이기 미설정·스크립트 실행 시에만 적용하며 그 외에는 내용과 최종 수치가 보인다. 데모는 live 놀이만 사용하며 검수 중 그림을 숨긴다. 웹 소개는 웹 실행과 공개 상세로, 토스 홍보의 시작·데모는 공식 토스 공유 링크로 연결한다. 토스 페이지는 웹·다른 기기 간 기록 자동 공유를 약속하지 않는다. 분석 스크립트·서비스 워커·외부 폰트를 추가하거나 기존 앱 경로를 변경하지 않는다.

#### Scenario: 데이터 기반 수치

- **WHEN** live 놀이 또는 재료 레지스트리가 바뀐 뒤 웹을 빌드한다
- **THEN** `/intro`의 놀이 수·준비 5분 이내 놀이 수·재료 수·월령 범위·발달영역별 수가 새 데이터로 계산된다.

#### Scenario: 소개 페이지 제공

- **WHEN** 처음 방문한 사용자가 `/intro`를 연다
- **THEN** 앱 온보딩이나 리다이렉트 없이 소개 페이지를 보고, 시작 버튼으로 `/`에, 둘러보기로 `/search`에 이동할 수 있다.

#### Scenario: 웹과 토스 홍보 경로 분리

- **WHEN** 사용자가 `/intro` 또는 `/toss-intro`를 연다
- **THEN** `/intro`는 토스 실행·소개 섹션 없이 기존 웹 시작·탐색·웹 상세 데모와 웹 FAQ를 제공한다. `/toss-intro`는 토스 전용 제목·설명·이용 방법·FAQ를 제공하고 헤더·상단·하단·이용 안내의 시작 버튼과 데모 결과는 모두 `https://minion.toss.im/F3OAPpVy`로 연결한다. 웹 소개는 하단 보조 링크로만 둔다.

#### Scenario: 토스 안내의 정확성

- **WHEN** 사용자가 `/toss-intro`의 안내와 예시 화면을 확인한다
- **THEN** 토스앱 내 별도 설치·회원가입 없는 무료 이용과 다음 추천 시작 광고·실제 표시 후24시간 추가 광고 제한, 현재 토스앱 기기 저장과 웹/다른 기기 간 기록 미공유를 안내한다. 공통 웹 캡처는 웹 기능 예시임을 밝힌다.

#### Scenario: 미리 찾아보기

- **WHEN** 소개 페이지에서 월령 구간과 재료 칩을 고른다
- **THEN** 해당 월령과 겹치고 필수 재료가 모두 선택된 live 놀이 수와 최대 3개 결과를 보여 준다. 웹 결과는 공개 상세로, 토스 결과는 공식 토스 공유 링크로 연결한다. imageStatus=review 놀이는 기본 브랜드 이미지를 쓴다.

#### Scenario: 재료 기반 추천과 하루 놀이 미션 소개

- **WHEN** 사용자가 두 소개 페이지의 첫 화면·추천·기록 설명을 읽는다
- **THEN** 지금 쓸 재료와 아이 월령을 고르면 알맞은 놀이3개를 추천받고 하나씩 완료해 완성 묶음을 남기는 흐름을 보여 준다. ‘하루에3개씩 작은 미션처럼’은 가벼운 목표로 설명하며 날짜 변경 자동 초기화·하루 이용 제한·의무 완료·별도 보상을 약속하지 않는다. 남은 놀이를 다음 날 이어갈 수 있고3개 완료 후 다음 추천을 시작할 수 있다고 안내한다. 조건에 맞는 후보 부족은 가능한 놀이만 안내하며 미리보기 데모를 실제 홈 추천과 구분한다.

#### Scenario: 현재 웹 화면 캡처 갱신

- **WHEN** 서비스 UI 변경 뒤 소개 페이지의 화면 이미지를 갱신한다
- **THEN** 별도 로컬 주소의 테스트 게스트로 현재 5개 탭·홈 회차·재료 선택·탐색·상세 준비물/안전 팁·저장·전체 기록 요약과 완성 묶음 화면을390×844 DPR2로 촬영한다. 두 소개 페이지는 갱신된780×1688 PNG에서 만든 같은 해시 WebP를 사용하고 기록 소개 문구도 전체 기록 기준과 일치한다. 실제 사용자 데이터는 사용하지 않는다.

#### Scenario: 공유 주소

- **WHEN** Preview 또는 운영 빌드에서 소개 페이지를 생성한다
- **THEN** canonical·OG 주소가 해당 배포 origin의 각 `/intro`·`/toss-intro`로 분리되며 두 페이지는 같은 `/intro/media`의 해시 WebP를 공유한다. 로컬·Vercel에서 각 정적 경로를 제공한다.

#### Scenario: 동작 줄이기와 스크립트 미실행

- **WHEN** 기기의 동작 줄이기가 켜져 있거나 자바스크립트가 꺼진 상태로 `/intro`를 연다
- **THEN** 숨겨진 섹션 없이 모든 내용이 보이고 숫자·막대는 처음부터 최종 값으로 표시된다. 동작 줄이기가 켜져 있으면 재료 띠도 멈춘다.
