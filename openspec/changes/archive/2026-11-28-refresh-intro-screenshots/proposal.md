# Proposal

## Why

사용자가 intro와 toss-intro의 화면 예시가 예전 UI임을 확인하고 현재 화면으로 다시 촬영하도록 요청했다. 기존7장에는 예전4개 탭·홈·기록 화면이 남아 있었다.

## What Changes

- WEB-004의 실제 캡처7장을 현재 로컬 빌드의5개 탭·회차 도전·재료 선택·탐색·상세 준비물/안전 팁·저장·기록 화면으로 교체한다.
- 현재 전체 기록 기준과 완성 묶음에 맞춰 기록 alt와 소개 문구를 수정한다.
- 두 소개 페이지는 같은 해시 WebP를 공유해 함께 갱신한다.
- WEB-001/002/003, LOC-001, PRI-001, TOSS-001/002와 웹/토스 실행 경로·기기 저장·광고 경계를 유지한다. 앱 UI·추천·실제 콘텐츠 승인·사용자 데이터·분석 동작은 변경하지 않는다.
