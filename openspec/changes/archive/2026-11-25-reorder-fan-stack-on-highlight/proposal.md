# 강조 카드 뒤의 겹침 순서 보정

## Why

사용자 캡처에서 왼쪽3번 강조가3/1/2, 오른쪽1번 강조가1/3/2로 보인다. 앞 카드만 올리고 뒤의 기본 z순서를 유지하기 때문이다.

## What Changes

- LOG-004: 모바일 강조 카드와 번호상 가까운 카드부터 전체 레이어를 다시 정한다. 왼쪽3번은3/2/1, 오른쪽1번은1/2/3이며 기본 순서와 기준 위치/크기는 유지한다.
- LOG-004: 동률은 해당 열의 기본 방향을 따르고 강조 해제 시 기본 순서로 복원한다. 마우스와 키보드가 같은 로직을 사용한다.
- LOG-001/003·LOC-001/002·REC-004·WEB-002·TOSS-003/006의 데이터·스프링·두 열·간격·빈 곳 접기·카드 상세·모션 감소·월별/넓은 화면·eval 차단은 유지한다.

## Capabilities

### Modified Capabilities

- `play-records`: 모바일 강조 전환의 전체 레이어 순서.

## Impact

원본 preview의 기존 모션 helper/회귀·팬과 현재 spec/활성 delta/정책 근거를 갱신한다. 기존 미커밋 변경을 보존하고 커밋·푸시·배포·토스 파일 재생성은 하지 않는다.
