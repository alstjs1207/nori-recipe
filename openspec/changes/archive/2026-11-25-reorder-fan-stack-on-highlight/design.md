# 강조 기준의 전체 레이어

기존 모바일 기본 레이어는 왼쪽1/2/3·오른쪽3/2/1이며 강조한 카드에만 z5를 부여했다. 이 때문에 반대 끝을 강조하면 남은 두 장의 순서가 거꾸로 보였다. getFanStackLayer에서 강조한 번호와의 거리를 먼저 정렬하고 같은 거리라면 열의 기본 방향을 따른다. 세 카드에3/2/1을 모두 적용하므로 한 카드만 올리지 않는다.

활성 카드가 없거나 동작 줄이기면 열의 기본 표지 번호를 앞에 둔다. 좌표·크기·스프링과 활성 입력 우선순위는 변경하지 않는다. 넓은 화면의 기존 레이어와 포커스/호버 동작은 그대로 둔다.
