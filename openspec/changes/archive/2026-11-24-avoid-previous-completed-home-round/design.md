# Design

실제 활성 완료 기록이3개인 상태에서만 새 회차 경로를 실행한다. 직전 회차 ID 집합으로 후보를 분리해 대안 풀을 기존 recommend로 순위화한다.3개 미만이면 직전 풀을 동일 엔진으로 순위화해 부족한 수만 덧붙인다. 대안에 조건부 상위 월령이 있으면 보충 풀에서는 상위 월령을 제외해 전체 최대1개를 보존한다.

이전 회차 ID를 최근12기록에서 추정하지 않고 실제 round.ids에서 받는다. 결과와 새 회차·빈 완료 참조는 기존 원자 저장에 맡긴다. 실패하면 이전 회차가 보존되어 재시도에서도 같은 직전 ID를 제외한다. 새 회차 생성 직후 재실행해도 같은 ID를 고정한다.
