# 전체 완료 후 직전 놀이 반복 최소화

## Why

2026-11-24 사용자가3개 모두 완료 후 다음 추천에서는 직전 놀이를 제외하고 대안이 부족한 경우에만 다시 추천하도록 요청했다. 기존 재료 우선 정렬에서는 같은3개가 다시 선정될 수 있었다.

## What Changes

- REC-004: 전체 완료 후 명시적 다음 추천에 한해 직전 회차3개를 제외한 적격 대안을 먼저 선택한다. 대안0/1/2/3개 이상이면 부족한3/2/1/0칸만 적격 직전 놀이로 보충한다.
- REC-002: 다음 회차의 직전 제외를 재료 정합도보다 먼저 적용하며, 각 후보 풀 안에서는 기존 재료 순위를 유지한다.
- REC-001/003: 안전·게시·월령·제외 재료·장소·시간·보호자 확인과 합친 결과의 조건부 상위 월령 최대1개를 유지한다.
- 부분 완료 보존,0/3 재료 재추천,회차 저장 실패 복구,누적 기록/묶음,0/3 새 회차 시작은 유지한다. 완료 후 재료 선택 안내를 실제 보충 동작에 맞춘다.

## Capabilities

### Modified Capabilities

- `recommendations`: REC-002·REC-004 다음 회차의 대안 우선과 적격 보충.
