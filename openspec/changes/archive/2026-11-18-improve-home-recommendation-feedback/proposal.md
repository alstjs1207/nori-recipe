# Proposal

## Why

홈 추천의 큰 카드와 작은 카드 사이에 상황별 탐색이 배치되어 모바일에서 한 세트임을 알아보기 어렵다. 완료 배지가 약하고 다른 놀이 기록 화면에 이전 스크롤이 복원된다.

## What Changes

- REC-004: 웹/토스 홈 추천을 공통 제목과 완료 개수 아래 연속 배치하고 상황별 탐색을 세트 뒤로 이동한다. 완료한 추천은 흐린 그림·도장으로 구분하며 링크와 찜은 유지한다.
- LOG-001: 웹 WebPage와 네이티브 ScrollView를 놀이 ID별로 새로 구성해 다른 놀이 기록 진입 시 맨 위에서 시작한다.
- REC-002/004의 재료 우선 순위·최근 완료 보충·고정 ID와 전체 완료 기준은 유지한다. 재추천 제외 정책·새 세트 자동 생성은 변경하지 않는다.
- LOC-001/002, PRI-001/002/003/004, WEB-001/002/003, TOSS-002/007의 저장·분석·공유·광고 정책을 유지한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `recommendations`: 연속된 추천 세트와 선명한 완료 표시.
- `play-records`: 다른 놀이 기록 화면의 초기 스크롤.
