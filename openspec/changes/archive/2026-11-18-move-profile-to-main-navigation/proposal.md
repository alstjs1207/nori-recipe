# Proposal

## Why

사용자가 검토안대로 상단 월령 버튼을 제거하고 하단 오른쪽에 마이페이지를 추가하며 월령은 홈 설명으로 옮기도록 요청했다. 작은 화면의5개 메뉴는 짧은 `마이` 표기를 사용한다.

## What Changes

- WEB-006: 상단 월령 버튼을 제거하고 웹/PWA/토스 공통 메뉴를 발견·탐색·저장·기록·마이5개로 구성한다. 데스크톱에도 같은 마이 진입을 제공한다.
- 하단을5등분해320px 화면에서 겹치지 않는 전체 칸을 터치할 수 있게 한다. 보이는 라벨은 마이, 접근성 이름은 마이페이지다. /mypage와 /settings에서는 마이를 선택 표시한다.
- 홈 설명은 실제 월령의 `N개월 아이에게 맞춘 놀이`를 모바일/데스크톱에 표시한다. 네이티브의 기존5번째 마이페이지 라벨도 마이로 줄이고 홈 월령 문구를 추가한다.
- WEB-002/005, REC-001/002/003/004/005, ONB-001/002, LOC-001/002, LOG-001/002/003, PRI-001/002/003/004, TOSS-001/002/003/007의 셸·안전 여백·상세/피드백 메뉴 숨김·새 진입·목록 복귀·추천·데이터·분석·광고 정책은 유지한다. 회원가입·서버 계정·새 저장은 추가하지 않는다.
