# Proposal

## Why

사용자가 혼합 추천 개수 안내 제거와 추천3개 완료 후 홈 재진입 때마다 반복되는 폭죽 수정을 요청했다. 기존 HomeRedesign은 저장 여부와 무관한 allCompleted를 폭죽 활성 조건으로 사용해 재마운트 시 과거 완료 기록만으로 재생했다.

## What Changes

- REC-002: 선택 재료 활용 놀이가 일부인 혼합 추천의 개수 안내만 제거한다. 관련 후보가 전혀 없는 경우와 전체 추천의 추가 준비물 안내는 유지한다.
- REC-004: 성공한 저장의 일회성 이벤트를 기록 ID·게스트·추천 세트와 대조한다. 해당 기록 전에는 미완료, 후에는3개 전체 완료인 경우에만 홈 복귀 직후 재생한다. 기존 완료 로드·홈 재진입·재실행·중복 기록은 재생하지 않는다.
- REC-001/003/005, LOG-001/002/003, LOC-001/002, WEB-002/005/006, TOSS-007의 추천 안전·고정·기록·저장·탐색·광고 정책을 유지한다. 동작 줄이기·홈 이탈·약3.3초 자동 종료를 유지한다.
