## MODIFIED Requirements

### Requirement: REC-002 재료 우선 순위와 점수

엔진 SHALL 필수 준비물의 선택 재료 일치를 완비·부분 일치·무재료·무관 순으로 비교한다. 부분 일치는 추가 필수 재료 수, 충족률, 일치 수를 비교하고 최근 완료·발달 다양성·소프트 점수는 그 우선순위를 뒤집지 않는다. 선택 준비물만의 일치는 주재료 활용 근거가 아니다. 일부만 선택 재료를 활용하는 혼합 추천의 개수 안내 문구는 표시하지 않으며, 관련 후보가 전혀 없는 경우와 전체 추천의 추가 준비물 안내는 유지한다.

#### Scenario: 부분 일치

- **WHEN** 도구가 일치하지만 추가 준비물이 필요하다
- **THEN** 무재료·무관 후보보다 우선하며 부족한 준비물을 안내한다.

#### Scenario: 다양성

- **WHEN** 더 나은 재료 일치와 다른 발달 영역이 경쟁한다
- **THEN** 재료 우선순위를 유지한다.

### Requirement: REC-004 홈 추천 고정과 완료 표현

홈 SHALL 재료 기준3개를 목표로 추천을 고정 보관하고 같은 문맥의 순위 변경만으로 바꾸지 않는다. 완료 상태·모두 완료 메시지는 유지하고 축하 효과는 마지막 미완료 추천의 저장으로 전체 완료가 된 직후 한 번만 재생한다. 웹/PWA/토스의 효과는 화면 전체에 약3.3초 표시하고 조작을 막지 않으며 홈 이탈·동작 줄이기에 제거한다. 웹/토스는 큰 카드와 나머지 카드를 공통 제목·완료 개수 아래 연속 배치하고 상황별 탐색은 뒤에 둔다. 완료 카드는 흐린 그림과 꽃 로고·`참 잘했어요`·`놀이 완료` 원형 도장으로 구분하고 다시 열 수 있다. 도장 위치·회전은 포인터로 바뀌지 않는다. 월령·재료·제외 재료·준비 확인·콘텐츠 적격성이 달라지면 복구한다. 현재 키에는 놀이 개수도 포함된다. 고정 UI 전체와 다음 세트 시점은 GAP-001·GAP-002 검증 대상이다.

#### Scenario: 같은 문맥

- **WHEN** 점수만 달라지고 기존 항목은 적격이다
- **THEN** 저장된 추천 ID를 유지한다.

#### Scenario: 재료 편집

- **WHEN** 오늘 재료를 변경한다
- **THEN** 기존 세트와 보호자 확인을 폐기한다.

#### Scenario: 삭제·부적격

- **WHEN** 저장된 놀이가 없어지거나 적격성을 잃는다
- **THEN** 현재 후보로 세트를 보충한다.

#### Scenario: 웹 추천 세트와 완료 카드

- **WHEN** 웹 홈에서 추천 중 일부를 완료한다
- **THEN** 같은 추천 ID를 유지하며 완료 개수와 해당 카드의 도장을 표시하고 상황별 탐색을 추천 사이에 끼우지 않는다. 대표 그림의1:1 공간은 로딩 전에 확보해 목록 복귀 후 레이아웃이 밀리지 않게 한다.

#### Scenario: 완료 도장에 영향을 주지 않는 대표 이미지 효과

- **WHEN** 좁은 화면을 포함해 완료한 대표 추천 카드에 포인터를 올리거나 벗어난다
- **THEN** 대표 그림의 스타일이 도장에 적용되지 않으며 도장은 같은 위치·회전을 유지한다.

#### Scenario: 전체 화면 축하와 종료

- **WHEN** 웹/PWA/토스에서 마지막 미완료 추천의 기록 저장이 성공해 추천3개 전체 완료로 바뀌고 홈에 복귀한다
- **THEN** 완료 배너를 유지하며 현재 화면 전체에서 축하 효과를 한 번 재생한다. 스크롤·메뉴/버튼 조작을 허용하고 약3.3초 후 또는 다른 화면으로 이동하면 효과를 제거한다.

#### Scenario: 완료 후 홈 재진입

- **WHEN** 추천3개가 이미 완료된 상태에서 검색·다른 페이지 방문 후 홈 복귀, 새로고침 또는 앱 재실행을 한다
- **THEN** 완료 배너·도장은 유지하되 축하 효과는 재생하지 않는다. 완료한 놀이를 다시 기록해도 재생하지 않는다.

#### Scenario: 동작 줄이기

- **WHEN** 사용자가 동작 줄이기를 설정했거나 축하 중 설정을 활성화한다
- **THEN** 폭죽을 표시하지 않거나 즉시 제거하며 완료 메시지는 유지한다.
