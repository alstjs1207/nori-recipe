## MODIFIED Requirements

### Requirement: WEB-004 정적 서비스 소개 페이지

웹 빌드 SHALL 앱과 분리된 정적 소개 페이지 `/intro`를 생성한다. 놀이·재료·월령·발달영역 수치는 live 놀이와 검수 대기 제외 재료에서 계산한다. 화면 이미지는 실제 웹 캡처의 내용 해시 WebP를 쓰고 브랜드명은 ‘노리 레시피’로 표기한다. 동작 효과는 동작 줄이기 미설정·스크립트 실행 시에만 적용하며 그 외에는 내용과 최종 수치가 보인다. 데모는 live 공개 상세 링크만 사용하며 검수 중 그림을 숨긴다. 토스 이용 안내와 정식 HTTPS 공유 링크를 제공하고 웹·토스·다른 기기 간 기록 자동 공유를 약속하지 않는다. 분석 스크립트·서비스 워커·외부 폰트를 추가하거나 기존 앱 경로를 변경하지 않는다.

#### Scenario: 데이터 기반 수치

- **WHEN** live 놀이 또는 재료 레지스트리가 바뀐 뒤 웹을 빌드한다
- **THEN** `/intro`의 놀이 수·준비 5분 이내 놀이 수·재료 수·월령 범위·발달영역별 수가 새 데이터로 계산된다.

#### Scenario: 소개 페이지 제공

- **WHEN** 처음 방문한 사용자가 `/intro`를 연다
- **THEN** 앱 온보딩이나 리다이렉트 없이 소개 페이지를 보고, 시작 버튼으로 `/`에, 둘러보기로 `/search`에 이동할 수 있다.

#### Scenario: 토스 인앱 소개와 실행

- **WHEN** 사용자가 소개 페이지에서 토스 이용 안내 또는 토스앱 열기 버튼을 선택한다
- **THEN** 안내는 별도 앱 설치·회원가입 없이 이용하는 방법과 현재 토스앱 기기 저장·웹/다른 기기와 자동 공유되지 않는 경계를 보여 주며, 실행 버튼은 사용자가 제공한 `https://minion.toss.im/F3OAPpVy`로 이동한다. 웹 시작·놀이 둘러보기는 계속 사용할 수 있다.

#### Scenario: 미리 찾아보기

- **WHEN** 소개 페이지에서 월령 구간과 재료 칩을 고른다
- **THEN** 해당 월령과 겹치고 필수 재료가 모두 선택된 live 놀이 수와 최대 3개의 공개 상세 링크를 보여 준다. imageStatus=review 놀이는 기본 브랜드 이미지를 쓴다.

#### Scenario: 공유 주소

- **WHEN** Preview 또는 운영 빌드에서 소개 페이지를 생성한다
- **THEN** canonical·OG 주소가 해당 배포 origin의 `/intro`로 채워진다.

#### Scenario: 동작 줄이기와 스크립트 미실행

- **WHEN** 기기의 동작 줄이기가 켜져 있거나 자바스크립트가 꺼진 상태로 `/intro`를 연다
- **THEN** 숨겨진 섹션 없이 모든 내용이 보이고 숫자·막대는 처음부터 최종 값으로 표시된다. 동작 줄이기가 켜져 있으면 재료 띠도 멈춘다.
