# Proposal

## Why

사용자가 전수 조사 후 새 진입은 맨 위, 뒤로 목록 복귀는 기존 위치, 미저장 기록은 보존하도록 전체 수정을 요청했다. 기존 WebPage가 모든 포커스에 같은 스크롤을 복원해 동일 놀이·기록·새 검색·설정 진입이 중간에서 시작했다.

## What Changes

- WEB-005: 공통 진입 분류·명시적 Link/router 진입·브라우저/화면/네이티브 목록 뒤로 복귀·스크롤 복원을 추가한다. 같은 페이지 링크도 새 진입으로 처리한다. Tabs는 반복 방문도 보존하는 fullHistory를 사용하며 과거 reset 플래그가 뒤로 복귀할 때 입력을 지우지 않도록 한다.
- CAT-002/004: 새 상황/영역 검색과 상세 진입은 위에서 시작하고 새 상세의 탭은 기본값으로 초기화한다. 목록으로 뒤로가기는 필터와 위치를 보존한다.
- LOG-001: 입력을 스크롤에서 분리해 현재 앱 세션에서 guestId/놀이 ID별 초안을 보존한다. 성공한 저장의 제출 버전만 제거하고 실패·다른 놀이 이동·미저장 중 재진입은 입력을 유지한다.
- 설정 새 진입은 상단, 개인정보 목적은 실제 DOM 마운트 후 해당 문단. 네이티브의 외곽 ScrollView에도 동일 정책을 적용한다.
- ONB-001/002, REC-001/002/003/004/005, LOG-002/003, LOC-001/002, PRI-001/002/003/004, WEB-001/002/003/004, TOSS-002/003/007의 게스트·추천·완료·동의·분석·공유·광고 정책은 유지한다. 초안은 완료 기록·영구 저장·동기화가 아니며 분석하지 않는다.
- GOV-002/003의 source-index 분류에 새 navigation/초안 모듈을 연결한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `web-platform`: 진입 방향을 구분한 공통 스크롤 정책.
- `catalog`: 새 검색·상세 초기화와 목록 복귀 보존.
- `play-records`: 놀이별 미저장 초안 보존.
