## MODIFIED Requirements

### Requirement: CAT-002 검색과 준비 완료

검색 SHALL NFKC 정규화 후 제목·태그·단계·효과·팁·발달영역·재료·장소 텍스트를 검색하고 월령·장소·시간·분류·준비 상태·제외 재료를 함께 적용한다. 준비 완료는 필수 재료 전체가 보유 목록에 있는 경우다. 검색의 시간 필터는 durationMax이며 추천의 durationMin 배수와 구분한다. 웹/PWA 탐색은 생년월 대신 개월 단위 휠로 월령을 선택하고 적용 시 검색에만 반영한다. 취소·닫기는 기존 필터를 유지하고 전체 월령·우리 아이 월령으로 돌아갈 수 있다.

#### Scenario: 준비 완료

- **WHEN** 필수 재료가 하나라도 부족하다
- **THEN** 준비 완료 필터에서 제외한다.

#### Scenario: 검색어 없음

- **WHEN** limit을 지정하지 않고 빈 검색어로 조회한다
- **THEN** 기본 최대 24개를 반환하며 검색어가 있으면 기본 최대 30개를 반환한다.

#### Scenario: 탐색 월령 휠 적용

- **WHEN** 탐색의 월령 버튼에서 0~48개월 휠을 조작하고 적용한다
- **THEN** 해당 월령으로 검색하며 아이의 생년월·프로필·기록은 바꾸지 않는다. 상세 방문 후 복귀해도 필터를 유지한다.

#### Scenario: 월령 선택 취소와 바로가기

- **WHEN** 휠 값을 바꾼 뒤 취소·닫기·Escape를 누른다
- **THEN** 기존 월령 필터를 유지한다. 재진입하면 적용된 값으로 열리고 전체 월령·저장된 우리 아이 월령을 선택해 적용할 수 있다.

### Requirement: CAT-004 상세 가이드·준비·안전·이미지

상세 SHALL 준비물·준비 조건·순서·팁·안전 안내를 제공하고 콘텐츠 안전 문구에 재료별 안내를 중복 없이 보강한다. imageStatus=review인 그림은 일반 놀이 이미지로 노출하지 않고 기본 표시를 사용한다. 안전 문구는 현재 제품 구현의 계약이며 의학적 안전 검증 완료를 뜻하지 않는다. 웹 상세에서 뒤로가기는 직전에 방문한 탭으로 돌아가며 탐색의 검색 조건과 스크롤 위치를 보존한다. 복귀 이력이 없는 직접 링크는 발견으로 돌아간다.

#### Scenario: 안전 보강

- **WHEN** 작은 부품 등 해당 재료가 있다
- **THEN** 재료별 유의사항을 기존 안내에 보강한다.

#### Scenario: 미검수 그림

- **WHEN** imageStatus가 review이다
- **THEN** 플랫폼의 기본 표시를 사용한다.

#### Scenario: 탐색으로 복귀

- **WHEN** 검색어와 필터를 적용한 탐색에서 놀이 상세를 연 뒤 화면의 뒤로가기 또는 브라우저 뒤로가기를 누른다
- **THEN** 탐색 탭으로 돌아가 검색어·필터·스크롤 위치를 유지한다.

#### Scenario: 상세 직접 방문

- **WHEN** 내부 방문 이력 없이 상세 직접 링크를 열고 화면의 뒤로가기를 누른다
- **THEN** 발견으로 이동한다.
