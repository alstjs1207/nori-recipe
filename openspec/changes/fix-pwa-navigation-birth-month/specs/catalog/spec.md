## MODIFIED Requirements

### Requirement: CAT-004 상세 가이드·준비·안전·이미지

상세 SHALL 준비물·준비 조건·순서·팁·안전 안내를 제공하고 콘텐츠 안전 문구에 재료별 안내를 중복 없이 보강한다. imageStatus=review인 그림은 일반 놀이 이미지로 노출하지 않고 기본 표시를 사용한다. 안전 문구는 현재 제품 구현의 계약이며 의학적 안전 검증 완료를 뜻하지 않는다. 웹 상세에서 뒤로가기는 직전에 방문한 탭으로 돌아가며 탐색의 검색 조건과 스크롤 위치를 보존한다. 복귀 이력이 없는 직접 링크는 발견으로 돌아간다.

#### Scenario: 안전 보강

- **WHEN** 작은 부품 등 해당 재료가 있다
- **THEN** 재료별 유의사항을 기존 안내에 보강한다.

#### Scenario: 미검수 그림

- **WHEN** imageStatus가 review이다
- **THEN** 플랫폼의 기본 표시를 사용한다.

#### Scenario: 탐색으로 복귀

- **WHEN** 검색어와 필터를 적용한 탐색에서 놀이 상세를 연 뒤 화면의 뒤로가기 또는 브라우저 뒤로가기를 누른다
- **THEN** 탐색 탭으로 돌아가 검색어·필터·스크롤 위치를 유지한다.

#### Scenario: 상세 직접 방문

- **WHEN** 내부 방문 이력 없이 상세 직접 링크를 열고 화면의 뒤로가기를 누른다
- **THEN** 발견으로 이동한다.
