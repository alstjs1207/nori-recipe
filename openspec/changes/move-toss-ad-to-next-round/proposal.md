# Proposal

## Why

기존 TOSS-007은 세 번째 놀이를 저장하고 홈에 돌아올 때 광고를 표시해 기록 직후 광고를 받는 흐름이었다. 사용자가 완료는 축하로 마치고 홈의 명시적 다음 시작에서만 광고를 안내·표시하며 실제 표시부터24시간 광고를 제한하도록 요청했다.

2026-11-26 후속: 완료 후 재료 저장으로도 새 회차를 시작할 수 있는데 광고 확인이 홈 CTA에만 연결돼 우회되는 결함을 수정한다. TOSS-007·REC-004의 공통 확인 흐름을 홈 CTA·홈 재료 저장·설정 재료 저장에 공통 hook을 적용한다. 설정은 선택창을 열기 전에 실제 회차 완료 기록을 읽으며 조회 실패 시 저장/새 회차를 시작하지 않고 재시도를 안내한다. 선택창 열기/진행 중 재료 변경에는 광고를 넣지 않고 취소/실패의 초안·기존 진행·LOG-001/004 누적 기록을 보존한다.

2026-11-26 표시 보완: TOSS-007의 팝업 제목을 ‘광고 안내’로 줄이고 본문 아래 구분선을 제거하며 버튼 앞24px 여백을 둔다. 확인/취소·새 회차·24시간·광고 처리 동작은 유지한다.

## What Changes

- TOSS-007: 광고를 홈의 ‘다음 놀이 3개 시작’으로 옮기고 클릭 후 확인 팝업(광고·24시간 안내, 취소 시 기존 진행 보존)·실제 show부터24시간·실패 즉시 진행·늦은 콜백 무시·닫힘 누락 복구를 구현한다.
- REC-004: 웹/PWA/토스 홈에 현재 재료로 다음 회차를 시작하는 CTA와 별도 재료 편집을 제공한다. 기존 회차 선택·안전·대안 우선·보호자 준비 확인 초기화·누적 기록·도장은 유지한다.
- TOSS-002/005, LOC-001/002: 마지막 표시 시각만 사용자별 기기에 추가 보관하고 전체 로컬 초기화에 삭제한다. guestId·기존 데이터·기록 스키마와 ONB-001/002의 온보딩·프로필 정책은 유지한다.
- TOSS-006: 테스트/운영 ID 분리 정책은 유지하고 보고서 지면명을 실제 동선과 맞춘다. LOG-001/004의 기록·완료 묶음과 PRI-001/002/003/004의 분석 범위를 유지한다.
- `add-toss-completion-ad`의 과거 완료시점 광고 설계를 대체한다. 그 change의 QR 실기기 미검증은 이번 다음시작 동선으로 남긴다. `add-same-material-recommendation-refresh` 중 웹 CTA만 이번 범위에 포함하며 네이티브·안전후보0~2개 결정 등 나머지를 완료로 표시하지 않는다.

## Capabilities

없음.

## Impact

원본 `/Users/msyu/study/play-recipe`의 기존 `preview`에서 작업한다. 별도 worktree/clone을 생성하지 않는다. SDK3.10.0과 광고 그룹 환경변수 이름은 호환을 위해 유지한다. 외부 광고의 실제 노출·클릭은 자동화하지 않는다. 초기 구현은 로컬 검증 범위였다.2026-11-26 사용자가 로컬 확인 후 현재 변경의 preview 커밋·푸시를 요청했다. 운영 main 병합·토스 콘솔 업로드는 별도 요청 범위로 유지한다.
