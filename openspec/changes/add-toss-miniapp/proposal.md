# Proposal

## Why

사용자는 기존 웹서비스를 유지하며 앱인토스에 로그인·결제·광고 없는 핵심 기능을 출시할 준비를 요청했다. 현재 Expo 웹에는 토스 SDK·사용자별 저장·공유·내비게이션 연결이 없다.

## What Changes

- 공식 WebView SDK 3.x와 별도 토스 번들/검증/출시 안내를 추가한다.
- 빌드 시 런타임을 분리해 기존 웹/네이티브의 저장 키·기능·배포를 보존한다.
- 토스 사용자 식별키별 네이티브 저장, 재시도 가능한 시작 실패, 공유 링크·클립보드·뒤로가기·안전 영역을 연결한다.
- 토스에서는 설치·웹 분석 유도를 숨기고 공통 내비게이션·플로팅 탭바·AI 삽화 고지·전용 개인정보 안내를 제공한다.
- 기존 ONB-001, LOC-001/002, WEB-001/002/003, PRI-001/002/003/004의 웹/네이티브 정책을 유지한다. GOV-001/002의 명세·근거 관리 절차를 따른다. 추천·안전·콘텐츠 승인 정책은 변경하지 않는다.
- LOG-001/003의 기록 검증·로컬 찜/기록, CAT-001/004의 공개 콘텐츠·상세 안전 안내, REC-001/003의 안전 필터·추천 정책은 유지한다. 저장 초기 실패가 `loading`에 고정되는 경로만 오류/재시도 상태로 복구하며 기존 저장 키·데이터는 바꾸지 않는다.

## Capabilities

### New Capabilities

- `toss-miniapp`: 기존 핵심 기능의 토스 실행·로컬 데이터·탐색·공유·고지·출시 번들 계약.

### Modified Capabilities

없음. 웹/네이티브 계약은 유지하며 토스에만 별도 계약을 추가한다.

## Impact

`src/platform`, 공통 시작/저장 호출부, 웹 셸·설정·이미지·공유, Metro 대상 선택, SDK 의존성, 별도 빌드/검증 명령과 OpenSpec. 원본 `/Users/msyu/study/play-recipe`의 기존 preview checkout을 사용한다. 커밋·푸시·운영 배포·콘솔 등록은 이 구현의 완료로 간주하지 않는다.
