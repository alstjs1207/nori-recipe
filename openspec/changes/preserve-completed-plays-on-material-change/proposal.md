# 재료 변경 시 완료한 놀이를 유지하고 남은 놀이만 재추천

## Why

2026-11-19 사용자가 다음 정책을 확정하고 우선 OpenSpec 등록만 요청했다. 재료로 놀이를 찾는 행동이 이미 완료한 놀이의 진행을 없애지 않도록 한다.

2026-11-21 사용자가 최종 홈·기록 시안과 앞서 확정한 정책의 실제 구현을 요청했다. 기존 재료 저장마다0/3으로 초기화되는 동작을 변경하고, 완료 묶음 저장과 기록 화면을 함께 구현·검증한다.

## What Changes

- REC-004: 0/3에서 재료를 변경하면3개 모두 현재 조건으로 다시 추천하고0/3을 유지한다.
- REC-004: 1/3에서는 완료한1개와 도장을 유지하고 남은2개만, 2/3에서는 완료한2개와 도장을 유지하고 남은1개만 현재 재료 조건으로 다시 추천한다. 완료한 놀이는 남은 칸에 중복 추천하지 않는다.
- REC-004: 재료 변경만으로 유지된 완료 칸을 제거하지 않는다. 다른 적격 후보가 부족하면 적격한 미완료 놀이 일부는 그대로 남을 수 있다. 안전 조건을 완화하거나 부적격 놀이로3개를 채우지 않는다(REC-001, GAP-001 유지).
- REC-004: 3개를 모두 완료하면 완료 안내와 콘페티를 한 번 표시한다. 완료 후 재료 변경을 저장하면 다음 회차의3개 추천으로 바꾸고0/3부터 시작한다. 같은 재료를 다시 저장하거나 같은 놀이 ID가 재추천돼도 완료 후의 새 회차에는 이전 도장을 가져오지 않는다.
- 날짜 변경·재진입·재실행으로 진행을 초기화하지 않는다. 누적 놀이 기록은 보존하고 과거 이력 배지는 홈에 추가하지 않는다. 같은 놀이의 중복 기록은 이번 회차에서1개만 집계한다.
- LOG-004: 회차에서 실제 완료한 최종3개를 달성 날짜의 이미지 묶음으로 보존한다. 기록 기본 보기는 최근3묶음이며 개별 놀이와 분리하고 월별 전체 보기를 제공한다. 전체 기록 기준 요약·7개 발달영역과 접을 수 있는 ‘이런 놀이를 함께했어요’를 유지한다.
- LOC-001/002·LOG-001·TOSS-007: 기존 저장된 회차와 완료 참조를 보존하며, 실패/취소·오래된 요청의 복구 및 회차별 축하/광고 판정을 검증해야 한다. 실행 검증과 실기기 미확인 범위를 구분한다.
- REC-002/003/005, ONB-001/002, LOG-002/003, PRI-001/002/003/004, WEB-002/005/006의 재료 우선·준비 확인·개인화·누적 통계·저장 범위·분석·탐색 정책은 유지한다. 재료 재선택 시 미완료 후보의 보호자 준비 확인은 자동 재사용하지 않는다.
