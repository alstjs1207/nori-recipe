## MODIFIED Requirements

### Requirement: REC-004 홈 추천 고정과 완료 표현

홈 SHALL 적격 추천3개를 목표로 회차와 실제 완료 기록을 기기에 저장한다. 홈의 재료 저장은0/3이면 전체를 재추천하고,1/3·2/3이면 완료 카드·도장·진행을 유지하며 미완료 칸만 현재 조건으로 재추천한다. 완료 ID는 남은 칸에 중복 추천하지 않는다.3/3 후 재료 저장은 직전3개를 제외한 적격 대안을 먼저 고르고3개 미만이면 부족한 칸만 직전 놀이의 적격 후보로 보충한 다음, 다음 회차0/3으로 시작하며 누적 이력을 보존한다. 날짜·재실행·일반 순위 변경·전체 완료만으로 회차를 교체하지 않는다. 과거 이력 배지는 홈에 표시하지 않는다. 축하 효과는 마지막 미완료 추천의 실제 저장 직후 한 번만 재생하며 웹/PWA/토스에서 전체 화면 약3.3초, 홈 이탈·동작 줄이기 종료와 조작 허용을 유지한다. 자동 월령/콘텐츠 변화의 부적격 복구와 안전 후보 부족의 GAP-001은 유지한다.

#### Scenario: 같은 문맥

- **WHEN** 점수만 달라지고 기존 항목은 적격이다
- **THEN** 저장된 추천 ID를 유지한다.

#### Scenario: 재료 편집

- **WHEN** 완료 수가0/3인 상태에서 홈 재료 편집을 저장한다
- **THEN** 현재 조건으로3개 전체를 다시 추천하고0/3을 유지한다. 미완료 후보의 보호자 준비 확인은 자동 재사용하지 않는다.

#### Scenario: 한 개 완료 후 재료 편집

- **WHEN** 이번 추천의1개를 완료하고 홈 재료 편집을 저장한다
- **THEN** 완료한1개·도장·실제 기록 참조와1/3 진행을 유지하고, 그 ID를 제외한 적격 후보로 남은2개만 재추천한다.

#### Scenario: 두 개 완료 후 재료 편집

- **WHEN** A/B를 완료해2/3인 상태에서 홈 재료 편집을 저장하고 D가 남은 칸의 적격 후보로 선정된다
- **THEN** A✓/B✓/D와2/3을 표시한다. A/B가 새 재료 조건과 달라도 재료 편집만으로 완료 칸을 지우지 않는다. D의 실제 완료 저장에서3/3·콘페티 한 번을 표시한다.

#### Scenario: 대안 부족

- **WHEN** 미완료 칸을 채울 다른 적격 놀이가 부족하다
- **THEN** 적격한 미완료 놀이 일부를 유지할 수 있다. 완료 ID 중복·안전 조건 완화·부적격 놀이 유지로3개를 채우지 않으며 기존 GAP-001 경계를 보존한다.

#### Scenario: 삭제·부적격

- **WHEN** 저장된 놀이가 없어지거나 적격성을 잃는다
- **THEN** 안전 조건에 맞는 현재 후보로 보충한다. 유지된 놀이의 이번 회차 완료는 보존하고 새로 들어온 놀이의 과거 기록은 가져오지 않는다.

#### Scenario: 웹 추천 세트와 완료 카드

- **WHEN** 웹 홈에서 추천 중 일부를 완료하고 재료를 변경하지 않는다
- **THEN** 같은 추천 ID를 유지하며 완료 개수와 해당 카드의 도장을 표시하고 상황별 탐색을 추천 사이에 끼우지 않는다. 대표 그림의1:1 공간은 로딩 전에 확보해 목록 복귀 후 레이아웃이 밀리지 않게 한다. 완료 추천은 흐린 그림과 꽃 로고·‘참 잘했어요’·‘놀이 완료’ 원형 도장으로 구분하고 다시 열 수 있다.

#### Scenario: 재진입·다음 날·재실행의 부분 완료

- **WHEN** 이번 회차의2개를 완료한 뒤 다음 날 또는 앱을 다시 열어 홈에 진입한다
- **THEN** 같은 적격 추천 ID·2개 도장·2/3 진행을 유지하고 남은1개를 이어간다. 날짜 키나 최근 기록 표시 개수로 진행을 만료시키지 않는다.

#### Scenario: 같은 놀이를 다시 추천

- **WHEN** 이번 회차3개를 모두 완료한 뒤 홈 재료 편집 또는 ‘새 추천 받기’에서 재료를 저장한다
- **THEN** 직전3개를 제외한 적격 대안부터 추천하고 대안이3개 미만일 때만 부족한 칸을 직전 놀이로 보충한다. 같은 재료를 저장해도 이 우선순위를 적용한다. 새 회차는 도장 없이0/3부터 시작하며 반복 놀이의 이전 완료를 가져오지 않는다. 누적 기록은 유지하고 새 회차의 세 번째 실제 완료도 한 번 축하한다.

#### Scenario: 다음 회차 대안 수와 안전 조건

- **WHEN** 전체 완료 후 다음 추천에서 직전3개 외의 적격 대안이0·1·2·3개 이상이다
- **THEN** 각각 대안0·1·2·3개를 먼저 채우고 부족한 칸만 현재 조건에 적격한 직전 놀이로 보충한다. 재료 일치도가 더 높은 직전 놀이도 대안을 밀어내지 않는다. 게시·월령·제외 재료·장소·시간·보호자 준비 조건은 유지하며 합친 추천의 조건부 상위 월령은 최대1개다. 적격 보충도 없으면 빈 칸을 부적격 놀이로 채우지 않는다.

#### Scenario: 재료 편집 실패·취소·연속 요청

- **WHEN** 재료 편집을 취소하거나 저장이 실패하거나 재료 요청이 겹친다
- **THEN** 취소/실패는 기존 추천·완료 진행·재료를 보존한다. 성공한 최신 요청만 반영하고 미완료 카드 교체만으로 완료 개수·축하·완료 광고를 증가시키지 않는다.

#### Scenario: 완료 후 명시적 새 추천 대기

- **WHEN** 이번 회차3개를 모두 완료한다
- **THEN** 추천·3/3·완료 배너·도장을 유지하고 자동 교체하지 않는다. 같은 놀이의 반복 기록은 개수를 추가하거나 축하를 다시 재생하지 않는다.

#### Scenario: 이전 저장된 추천의 호환

- **WHEN** 회차 저장이 없지만 기존 고정 추천 ID와 완료 기록이 있다
- **THEN** 기존 추천의 활성 완료 기록을 최초 회차로 한 번 이전해 부분/전체 완료를 보존한다. 이후 새 회차에는 이전 이력을 다시 가져오지 않는다.

#### Scenario: 완료 도장에 영향을 주지 않는 대표 이미지 효과

- **WHEN** 좁은 화면을 포함해 완료한 대표 추천 카드에 포인터를 올리거나 벗어난다
- **THEN** 대표 그림의 스타일이 도장에 적용되지 않으며 도장은 같은 위치·회전을 유지한다.

#### Scenario: 전체 화면 축하와 종료

- **WHEN** 웹/PWA/토스에서 마지막 미완료 추천의 기록 저장이 성공해 추천3개 전체 완료로 바뀌고 홈에 복귀한다
- **THEN** 완료 배너를 유지하며 현재 화면 전체에서 축하 효과를 한 번 재생한다. 스크롤·메뉴/버튼 조작을 허용하고 약3.3초 후 또는 다른 화면으로 이동하면 효과를 제거한다.

#### Scenario: 완료 후 홈 재진입

- **WHEN** 추천3개가 이미 완료된 상태에서 검색·다른 페이지 방문 후 홈 복귀, 새로고침 또는 앱 재실행을 한다
- **THEN** 완료 배너·도장은 유지하되 축하 효과는 재생하지 않는다. 완료한 놀이를 다시 기록해도 재생하지 않는다.

#### Scenario: 동작 줄이기

- **WHEN** 사용자가 동작 줄이기를 설정했거나 축하 중 설정을 활성화한다
- **THEN** 폭죽을 표시하지 않거나 즉시 제거하며 완료 메시지는 유지한다.

#### Scenario: 작은 놀이 도전과 기록 연결

- **WHEN** 홈에 추천 놀이가 표시된다
- **THEN** 작은 ‘이번 놀이 도전’ 영역과0/3~3/3 진행을 표시하고 대표1개·하단2개 추천 구성을 유지한다.3개 완료 후에는 ‘세 가지 놀이 완성!’과 기록 바로가기를 제공한다.3개 미만 안전 후보는 빈 칸을 부적격 놀이로 채우거나 완료로 표시하지 않는다.
