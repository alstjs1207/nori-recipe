# 홈 세트 수와 전환 계약 정리

## Why

홈 정책과 구현의 경계가 문서만으로 확정되지 않는다. REC-001·REC-004 및 GAP-001·GAP-002를 다룬다.

## What Changes

- 과거 예정 작업을 추적 가능한 미구현 change로 정리한다.
- 상태: **제안·미착수 / 결정 필요**. 이번 도입에서 기능을 구현하지 않는다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `recommendations`: 기존 REC-001·REC-004에 연결되는 REC-006 후속 계약을 제안한다. 현재 구현에 대한 정책 결정과 실제 변경은 후속 요청 때 확정한다.

## Impact

홈 세트 수와 전환 계약 정리의 조사·정책 결정·호환 검증이 필요하다. 기존 데이터·서비스·승인 상태를 변경하지 않는다. 예정 업무의 기록은 신규 기능이나 운영 변경 승인이 아니다.
