## ADDED Requirements

### Requirement: CAT-005 최근 본 놀이 탐색

서비스 SHALL 현재 게스트가 실제로 연 공개 놀이 상세를 최근 본 목록에 표시하고, 동일 놀이는 한 번만 노출하며 재열람 시 맨 앞으로 이동시킨다. 목록에서 상세로 다시 이동할 수 있고 완료·찜·추천 피드백은 열람만으로 변경하지 않는다.

#### Scenario: 상세 열람과 재열람

- **WHEN** 사용자가 공개 놀이 A, B, A의 상세를 차례로 연다
- **THEN** 최근 본 목록은 A, B 순서이며 A는 중복되지 않는다.

#### Scenario: 목록 카드 노출만 발생

- **WHEN** 목록에서 카드만 보거나 잘못된 ID의 상세에 접근한다
- **THEN** 최근 본 항목을 생성하지 않고 완료·찜·피드백도 바꾸지 않는다.

#### Scenario: 콘텐츠 비공개 전환

- **WHEN** 최근 본 놀이가 삭제되거나 더 이상 공개 상태가 아니다
- **THEN** 사용자 목록에서는 제외하며 초안이나 보관 콘텐츠로 연결하지 않는다.

#### Scenario: 빈 목록

- **WHEN** 열람 이력이 없거나 목록을 비웠다
- **THEN** 빈 상태와 놀이 탐색 동선을 제공하고 완료 기록과 구분해 안내한다.
