## ADDED Requirements

### Requirement: LOC-003 최근 본 목록의 로컬 보관

서비스 MUST 최근 본 목록을 게스트별 로컬 데이터로 보관하고 재실행 후 복원한다. 목록은 최신 20개로 제한한다. 목록 비우기는 다른 활동을 보존하며 활동 초기화·전체 초기화 시 해당 게스트의 열람 목록도 지운다. 열람 목록과 열람 시각을 외부 분석으로 새로 전송하지 않는다.

#### Scenario: 기존 사용자와 보관 상한

- **WHEN** 기존 사용자가 처음 새 버전을 열거나 21번째 서로 다른 놀이를 연다
- **THEN** 기존 사용자는 빈 열람 목록으로 시작하며 상한 초과 시 가장 오래된 항목만 제외한다. 기존 찜·완료·guestId는 유지한다.

#### Scenario: 게스트 분리와 재실행

- **WHEN** 앱을 재실행하거나 다른 guestId로 조회한다
- **THEN** 현재 게스트의 목록만 복원하며 다른 게스트 목록을 섞지 않는다.

#### Scenario: 목록 비우기와 초기화

- **WHEN** 최근 본 목록 비우기 또는 활동·전체 초기화를 실행한다
- **THEN** 해당 열람 목록을 지운다. 목록 비우기만으로 찜·완료·추천 피드백·동의를 변경하지 않는다.

#### Scenario: 저장 또는 읽기 실패

- **WHEN** 열람 저장이 실패하거나 일부 로컬 데이터가 손상됐다
- **THEN** 놀이 상세 이용은 계속 가능하고 다른 사용자 데이터를 초기화하지 않으며 실패를 기록 성공으로 표시하지 않는다. 보존 가능한 기존 항목은 유지한다.
