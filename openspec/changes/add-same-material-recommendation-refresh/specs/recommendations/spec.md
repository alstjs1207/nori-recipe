## ADDED Requirements

### Requirement: REC-007 같은 재료로 다음 세트 요청

홈 SHALL 현재 세트를 모두 완료한 뒤 명시적 요청으로 같은 월령·선택 재료·제외 재료의 다음 세트를 제공한다. 진행 중 세트는 유지하며 REC-001~REC-003의 필터와 재료 우선순위를 보존한다. 같은 재료 우선순위의 후보에서는 직전 세트 밖의 놀이를 우선한다. 새 세트에 상위 월령 보호자 확인을 자동 재사용하지 않는다.

#### Scenario: 모두 완료한 뒤 요청

- **WHEN** 현재 세트를 모두 완료하고 같은 재료로 다음 추천을 요청한다
- **THEN** 재료 선택창을 강제로 열지 않고 적격 후보를 다시 평가해 다음 세트를 제시하며 기존 완료 기록·찜·선택 재료를 유지한다.

#### Scenario: 미완료 세트

- **WHEN** 현재 세트에 미완료 놀이가 있거나 단순 재진입·날짜 변경이 발생한다
- **THEN** 일반 점수 변화만으로 기존 적격 세트를 교체하지 않는다. 문맥 변경·삭제·부적격 복구는 기존 REC-004를 따른다.

#### Scenario: 다른 놀이가 일부만 존재

- **WHEN** 기존 순위·안전 조건을 유지하면서 일부 놀이만 바꿀 수 있다
- **THEN** 가능한 대안을 우선하고 유지된 놀이를 구분해 안내한다. 새로운 세트를 제공하려고 더 낮은 재료 우선순위를 승격하거나 안전 조건을 완화하지 않는다.

#### Scenario: 대안 없음

- **WHEN** 새로 제시할 적격 대안이 없다
- **THEN** 현재 세트를 유지하고 대안 부족 및 재료 변경·탐색 동선을 안내한다. 같은 세트의 순서만 바꿔 새 추천으로 표시하지 않는다.

#### Scenario: 전환 실패 또는 연속 요청

- **WHEN** 다음 세트 저장이 실패하거나 요청이 연속으로 발생한다
- **THEN** 실패 시 기존 세트를 유지하고 재시도할 수 있으며 동시에 여러 세트 전환을 적용하지 않는다.

#### Scenario: 전환 후 재실행

- **WHEN** 다음 세트를 저장한 뒤 앱을 다시 연다
- **THEN** 적격한 저장 세트를 복원하고 이전 세트 완료 이력만으로 새 세트 전체를 완료 처리하지 않는다.
