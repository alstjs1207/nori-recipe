# 같은 재료로 다른 추천 받기

## Why

현재 홈의 ‘새 추천 받기’는 재료 선택창을 열며, 같은 재료를 유지한 채 다음 놀이 세트로 넘어가는 명시적 흐름이 없다. 완료한 세트 이후에도 현재 재료로 이어서 놀 수 있도록 한다.

## What Changes

- 상태: **작업 예정·미착수**. 이번 요청은 계획 등록이며 추천 동작은 변경하지 않는다.
- 제안 범위는 현재 추천 세트를 모두 완료한 뒤 사용자가 명시적으로 다음 세트를 요청하는 흐름이다. 진행 중 개별 카드 교체·자동 날짜 갱신은 포함하지 않는다.
- 월령·선택 재료·제외 재료를 유지하고 기존 안전·재료 우선순위를 지키며 가능한 다른 놀이를 추천한다.
- 후보 부족·대안 없음·중복 클릭·저장 실패·재실행을 다룬다. 무작위 재정렬만으로 ‘다른 추천’을 표시하지 않는다.
- `clarify-home-set-lifecycle`의 REC-006 및 GAP-001·GAP-002와 연결한다. 세트 완료 기준·0~2개 정책은 구현 전 조율한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `recommendations`: REC-001~REC-005의 필터·순위·미완료 세트 고정을 유지하고 REC-007 명시적 다음 세트 전환을 추가한다. 기존 후속 REC-006을 중복 정의하지 않는다.

## Impact

- 예상 구현: `app/(main)/index.tsx`, `src/components/web/HomeRedesign.tsx`, `src/store/sessionStore.ts`, 추천 엔진과 관련 회귀.
- `HOME_RECOMMENDATION_RULES.md`는 후속 구현 시 합의한 계약과 함께 갱신한다. 현재 규칙을 이번 계획에서 덮어쓰지 않는다.
- 기존 guestId·찜·완료 기록과 추천 세트를 보존하고, 상위 월령 보호자 확인은 새 세트에 자동 재사용하지 않는다.
- 웹·네이티브 로컬 기능으로 계획하며 백엔드·신규 분석 이벤트·커밋·배포는 범위 밖이다.
