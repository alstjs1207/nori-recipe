# 게스트 시작·아이 월령·재료 설정

## Purpose

현재 코드·테스트와 기존 제품 정책을 대조한 계약이다. 검증 공백은 `openspec/known-gaps.md`, 완료 근거는 `openspec/completed-work.md`를 참고한다.

## Requirements

### Requirement: ONB-001 로컬 게스트와 선택적 프로필

서비스 SHALL 기기에 guestId를 생성·복원하며 웹에서는 회원가입 없이 월령만으로 추천을 시작할 수 있게 한다. 아이 이름과 가족 정보는 로컬 프로필이며 계정 인증을 뜻하지 않는다.

#### Scenario: 웹 첫 방문

- **WHEN** 가입하지 않은 보호자가 월령을 선택한다
- **THEN** 로컬 문맥을 저장하고 추천을 이용할 수 있다.

#### Scenario: 기존 방문

- **WHEN** 같은 저장소에서 다시 시작한다
- **THEN** 기존 guestId와 프로필·온보딩 상태를 복원한다.

### Requirement: ONB-002 월령 계산과 온보딩 기본값

서비스 SHALL 출생 월 인덱스와 실행 기기의 현재 연월 차이로 월령을 구하고 음수를 0으로 제한한다. 온보딩 기본 재료는 paper·bowl·cup·crayon이며 초기 추천 입력은 실내·20분이다. NEW의 한국 날짜 규칙과 월령 계산의 기기 시간대를 구분한다. 웹/PWA 첫 시작·설정은 생년월을 직접 입력받아 개월수를 자동 표시하고 출생월 인덱스를 그대로 저장한다. 신규 입력은 현재 월부터 48개월 전까지 허용하며 빈 값·잘못된 월·미래 월·범위 밖 신규 값은 저장하지 않는다. 기존 저장값은 48개월을 넘어도 자동으로 줄이거나 바꾸지 않는다.

#### Scenario: 초기 추천

- **WHEN** 출생 월이 없는 문맥을 추천 입력으로 변환한다
- **THEN** 입력 없음(null)을 반환한다.

#### Scenario: 기본 설정

- **WHEN** 온보딩 기본 문맥을 만든다
- **THEN** 기본 재료 및 실내·20분 입력을 사용한다.

#### Scenario: 생년월 직접 입력

- **WHEN** 보호자가 유효한 생년월을 입력한다
- **THEN** 기기 현재 연월과의 차이를 개월수로 즉시 표시하고 해당 출생월을 저장한다.

#### Scenario: 잘못된 입력

- **WHEN** 생년월이 비어 있거나 잘못된 월·미래 월·48개월 범위 밖의 신규 값이다
- **THEN** 안내를 표시하고 저장을 막으며 기존 설정을 보존한다.

#### Scenario: 기존 아이 정보 보존

- **WHEN** 저장한 출생월로 계산한 월령이 48개월을 넘어 설정을 연다
- **THEN** 실제 생년월과 개월수를 표시하며 이름만 저장해도 기존 출생월을 바꾸지 않는다.
